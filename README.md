# ABM CRM

ABM CRM quản lý bán hàng B2B và công việc đội sale theo lộ trình đầy đủ 12 module trong PRD.
CRM sử dụng hạ tầng Cloudflare, kết nối agent GoClaw qua Lark và lấy MISA AMIS làm nguồn thực thu.
Giai đoạn foundation chốt quyết định, mô hình dữ liệu, chính sách và bằng chứng PoC trước khi xây MVP1.

Xem [mục lục tài liệu](docs/README.md) để đọc yêu cầu nguồn và quy ước kỹ thuật.
